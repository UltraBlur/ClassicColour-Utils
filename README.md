# PR788 光谱采集工具使用说明

本工具用于通过串口连接 `PR788`，采集光谱数据，保存为 `CSV`，并在界面中查看当前测量结果、`SPD` 预览图和颜色预览。

当前图形界面位于 `ENV_PR788` 目录下，推荐通过 `ENV_PR788/main.py` 启动。

By：北京电影学院智能影像工程学院 高胡宇晨

## 1. 使用前准备

请先确认以下事项：

- `PR788` 已正确连接到电脑
- 已确认设备对应的串口号可以被系统识别
- Python 环境中已安装本工具所需依赖

建议至少具备这些依赖：

- `pyserial`
- `PyQt5`
- `colour`
- `numpy`

如果你之前装过错误的 `serial` 包，而不是 `pyserial`，串口功能会出问题。  
可以使用下面的方式修正：

```powershell
pip uninstall serial
pip install pyserial
```

## 2. 启动方式

推荐直接从 `ENV_PR788` 根目录启动：

```powershell
python ENV_PR788\main.py
```

如果使用指定 Conda 环境，例如：

```powershell
C:/Users/gaohu/.conda/envs/EleColor-Spec/python.exe c:/Users/gaohu/Desktop/ClassicColour-Utils/ENV_PR788/main.py
```

## 3. 界面功能说明

界面分为左右两部分。

各面板（左侧控制区 / 中间结果区 / 右侧历史区，以及中间区里 `SPD` 图与色度图）之间的深色竖条都可以直接左右拖动，调整各模块的宽窄比例。分割位置会被自动记住，下次启动时恢复。

### 左侧：控制区

左侧主要负责设备连接、保存设置和测量控制。

包括：

- 串口选择
- `PR788` 连接 / 断开
- 项目文件夹设置（保存目录）
- 文件名模板设置（支持子文件夹层级）
- 自动编号设置
- 测量按钮

### 中间：结果区

中间主要负责显示当前一次测量的结果。

包括：

- 当前文件名和保存路径
- `sRGB` 颜色预览块
- `SPD` 预览图
- 色度与白点参数
- 日志区

### 右侧：项目文件夹（文件管理器）

右侧是一个简单的文件管理器，浏览当前项目文件夹里的目录和 `CSV` 文件。

- 项目文件夹与左侧的保存目录是**同一个**：在右侧点 `Open Folder` 换文件夹，左侧路径会同步更新；反过来在左侧改路径，右侧目录树也会自动刷新。数据分析对话框读取的历史文件列表同样跟着这个文件夹走。
- 目录树只显示**目录和 `.csv` 文件**（其他文件、隐藏目录如 `.git` 不显示）。目录默认全部展开，空目录也会显示。
- 按钮：
  - `Open Folder` — 换项目文件夹
  - `New Folder` — 在当前项目文件夹下新建子目录（输入的名字会自动做文件名清理）
  - `Refresh` — 重新扫描目录树
  - `Open CSV` — 打开项目文件夹之外的任意 `CSV` 文件
- **点击某个 `CSV` 文件**会把它加载到中间结果区预览（不加载新测量，只是读取该文件）。
- 在文件 / 目录上**右键**：
  - `Open in Explorer` — 在资源管理器中打开（文件会直接选中）
  - `Copy Path` — 复制完整路径到剪贴板

## 4. 典型使用流程

### 第一步：启动程序

运行 `ENV_PR788/main.py` 后，界面会启动。

### 第二步：选择串口

在左上角串口下拉框中选择当前 `PR788` 对应的串口。  
如果刚插上设备，可以点击 `Refresh` 重新扫描串口。

### 第三步：连接 PR788

点击 `Connect PR788`。

点击后，软件会做的是：

- 打开当前串口
- 向 `PR788` 发送远程模式相关指令
- 在日志区记录当前操作

重要说明：

- 软件界面中的状态只表示“串口已打开且 remote 指令已发送”
- 这并不等于已经百分之百确认设备真正进入远程模式
- 是否真正连接成功，请以 `PR788` 设备屏幕上的显示为准
- 只有当 `PR788` 自身界面明确进入 `REMOTE MODE` 时，才应认为远程连接成功

如果连接失败：

- 请检查串口是否被其他软件占用
- 请检查串口号是否选错
- 请确认设备是否已经正常供电

### 第四步：设置项目文件夹

在 `Output Folder` 中选择保存 `CSV` 文件的项目文件夹。

右侧文件管理器会以这个文件夹为根显示目录树（也可以在右侧点 `Open Folder` 直接换文件夹，两边是同一个设置）。

### 第五步：设置文件名模板

文件名模板目前支持的占位符：

- `{counter}` — 自动编号（未启用编号时为空）
- `{timestamp}` — 时间戳 `2026-08-30_14.30.00.123456`
- `{date}` — 日期 `2026-08-30`

例如：

```text
{counter}_{timestamp}
```

或者：

```text
sample_{timestamp}
```

**支持子文件夹层级**：模板里直接写 `/`（或 `\`）就会创建子目录，每一级会单独做文件名清理，空段自动丢弃：

```text
{date}/{counter}_{timestamp}
```

会保存到：

```text
<项目文件夹>/2026-08-30/5_2026-08-30_14.30.00.123456.csv
```

不写 `/` 时行为和以前完全一样（直接存在项目文件夹根下）。界面会自动预览最终的相对文件名和完整保存路径。

### 第六步：设置自动编号

如果希望文件名自动带编号，可以勾选：

```text
Enable auto counter
```

可设置：

- `Start`
  起始编号
- `Step`
  每次测量后编号递增的步长
- `Current`
  当前将要使用的编号

点击 `Reset To Start` 可以把当前编号恢复到起始值。

说明：

- 当前自动编号完全由界面内部管理
- 不再依赖外部 `txt` 文件

### 第七步：开始测量

点击：

```text
Capture Measurement
```

程序会：

1. 触发 `PR788` 测量
2. 读取返回数据
3. 保存为 `CSV`
4. 更新右侧结果

开始测量前，请先确认：

- `PR788` 设备屏幕已经进入 `REMOTE MODE`

## 5. 关于等待时间

当前测量读取默认不会主动超时。

也就是说：

- 如果 `PR788` 某次读数很慢
- 程序会继续等待
- 不会因为固定的 30 秒或 60 秒限制而自动报错

这适合那些单次测量时间较长的场景。

## 6. 当前保存的数据格式

每次测量结果会保存为 `CSV` 文件。  
当前保存格式为两列数据：

```text
wavelength,value
```

文件内容不带表头，保存内容是从 `PR788` 读取并解析后的光谱数据。

## 7. 结果区怎么看

### 1. File / Path

显示当前这次测量保存后的文件名和路径。

### 2. sRGB Preview

显示当前测量结果换算后的 `sRGB` 预览颜色。

说明：

- 这是一个视觉参考色块
- 用于快速判断当前测量光色的大致观感
- 颜色由 `colour` 库根据当前测量结果计算得到

### 3. SPD Preview 380-780 nm

显示当前测量的 `SPD` 曲线。

特征：

- 横坐标为 `380–780 nm`
- 白色包络线表示光谱轮廓
- 曲线下方做了按波长的彩色填充

这张图主要用于现场快速查看当前光谱分布形状。

### 4. 色度图（Chromaticity）

显示当前测量积分得到的色坐标在 CIE 色度图中的位置，与 `SPD Preview` 左右并排。

- 右上角下拉框可切换坐标图：`CIE 1931 xy` / `CIE 1976 u'v'`
- **白色圆点（带暗环）为当前测量点**，灰色小圆点为 `D65` 参考白点
- 马蹄形轮廓为光谱轨迹，底部直线为紫线
- 马蹄形内部填充真实光谱色（单位亮度 XYZ → sRGB 逐像素换算，D65 参考）；色场管线与 **colour-science 库的 RGB 色度图色场一致**：先应用 sRGB 编码传递函数（不做预裁剪，超显示范围的值保留相对大小）、再逐像素按最大值归一、裁剪后做**轻微降饱和**（`_FIELD_SATURATION = 0.80`，1.0 即库的满饱和观感，可按喜好调整）、最后显示端裁剪。色场按 2× 超采样渲染后盒式下采样，马蹄形边缘为平滑灰阶过渡（无锯齿）；渲染分辨率封顶（长边 512），窗口缩放命中缓存、不重算；色场由 `ui/chromaticity_field.py` 统一生成

切换坐标图后，白色测量点会同步显示对应坐标下的位置，与下方指标卡数值一致。

### 5. CIE 1931 x y

显示当前测量的 `xy` 色坐标。

### 6. CIE 1976 u'v'

显示当前测量的 `u'v'` 坐标。

### 7. CIE XYZ

显示当前测量结果计算得到的 `XYZ` 值。

### 8. CCT (Ohno 2013)

显示当前测量结果的相关色温 `CCT`。  
当前算法使用：

```text
Ohno 2013
```

### 9. Luminance

显示当前测量结果的亮度，界面中按 `nit` 显示。

### 10. Tint (Duv, Ohno 2013)

显示当前的偏色程度，当前使用：

```text
Duv
```

通常可以这样理解：

- `Duv > 0`：偏绿
- `Duv < 0`：偏洋红 / 品红
- 越接近 `0`：越接近黑体轨迹

## 8. 数据分析功能（离线处理）

左侧控制区底部有 `Data Analysis` 按钮组，提供四个离线分析功能。它们都直接读取 `Output Folder` 中保存的历史 `CSV`，**不需要连接设备**。

> 前提：先把 `Output Folder` 指向存放 `CSV` 的目录，对话框里会自动列出该目录下的全部 `CSV`。

### 8.1 Compare SPDs（光谱对比）

- 左侧可 `Ctrl`/`Shift` 多选光谱曲线进行叠加显示
- `Normalize to peak (100%)`：把每条曲线归一化到峰值 100%，便于比较形状
- `Difference vs first selected`：为每条曲线追加一条相对第一条选中曲线的差值虚线
- 下方表格列出两两组合的颜色差异（ΔE）：
  - `ΔE76` / `ΔE94` / `ΔE2000`
  - `CMC 2:1` / `CMC 1:1`
  - `ITP (BT.2124)` / `ITP (P.143)`
- `Export ΔE CSV` 可以把整张表格导出为 `CSV`

说明：

- 光源的 ΔE 均基于色度计算（每条光谱先归一化到单位亮度），反映的是“色相”差异，不包含亮度差异
- ITP 是面向显示的色彩指标，用于光源时绝对值较大（可达上万量级），建议关注相对差异；`BT.2124` 会把 ΔT 项减半，`P.143` 则不减半
- 由于归一化到单位亮度，`CMC 2:1` 与 `CMC 1:1` 对光源是相等的（ΔL 恒为 0）

### 8.2 Spectral Ratio（光谱透过率 / 反射率）

用于测量样品的透过率或反射率：

1. 先测 `Reference`（参考光谱）：例如探头正对光源、无样品时的光谱
2. 再以同样几何关系测 `Sample`（样品光谱）：样品置于光路中（透过率），或取样品表面反射（反射率）
3. 对话框会逐波长计算 `Sample / Reference` 的百分比曲线，并给出最小 / 平均 / 最大统计
- 右侧色块显示样品作用后的光色（`xy` / `u'v'` / `CCT`）
- `Save Ratio CSV` 保存比例曲线

### 8.3 Gamut Coverage（色域覆盖，多基色 + 4 套 UCS）

- **多基色**：左侧 3–8 行动态基色行（默认 `R/G/B`，"+ Add primary" 增行、`×` 删行，每行可改任意单字母标签，如 `W`、`O`）——支持 WRGB / 多通道光源；至少选中 3 条光谱才计算
- **色域 = N 个基色的凸包**（所有混色的凸包区域）。当前 UCS 非仿射（u'v' / CIE 2000 / CAM16）时，边界由 xy 凸包边缘密采样 → 坐标变换 → 重新取凸包得到，所画区域紧包真实色域（出界部分被可见域 / 参考域交集裁掉）
- **覆盖率按重叠口径**（业界 "99% DCI-P3" 的算法），不是面积比：
  - `% visible = area(你 ∩ 可见域) ÷ area(可见域)`
  - `Covers ref % = area(你 ∩ 参考) ÷ area(参考)` —— 你的色域覆盖了参考色域百分之多少
  - `Ref covers you % = area(你 ∩ 参考) ÷ area(你)` —— 你的色域有多少落在参考色域内
- **UCS 选择**（顶部下拉，面积 / 百分比 / 表格 / 画布随之全部重算）：
  | UCS | 坐标 | 可见域面积 |
  | --- | --- | --- |
  | CIE 1931 xy | x, y | 0.3342 (xy²) |
  | CIE 1976 u'v' | u′, v′ | 0.1952 (u′v′²) |
  | CIE 2000 UCS (Luo 2006) | a′, b′ | 13530.8 (UCS²) |
  | CAM16-UCS (Li 2017) | a′, b′ | 13411.6 (UCS²) |
  - 两套 CAM 系的观察条件固定为 **D65 适应 · L = 40（80 cd·m⁻²）· average 环境 · CIE 标准系数（IEC 61966-2-1）**——显示语境的标准条件；色场背景在该亮度约定下逐像素反解 XYZ（固定亮度近似）
- **画布**（视觉层次：关键信息最亮、背景信息最弱）：
  - 主层（亮白）：**你的色域** = 白色凸包轮廓（半透明白填充）+ 白色基色圆点（带暗环）与标签
  - 次层（低饱和色）：勾选的参考色域，保留各自色相但降饱和、细线（近似项虚线）；`D65` 白点为灰色小点
  - 背景层：对应 UCS 的光谱色背景（colour-science 管线 + 轻微降饱和 + 边缘抗锯齿，见 §4）+ 380–780 nm 光谱轨迹 / 紫线（与主界面色度图共用 `ui/chromaticity_field.py`）
  - 左侧树形列表勾选 / 取消参考色域（`All` / `None`，悬停看标准与白点；条目颜色与画布一致）
- 顶部三项汇总：色域面积（UCS²）、% visible（重叠）、Covers sRGB（重叠）
- 下方表格（7 列）：Gamut / Standard / White / Area (UCS²) / % visible / Covers ref % / Ref covers you %

**各 UCS 下典型色域的 % visible（重叠口径，实测）**

| 色域 | CIE 1931 xy | CIE 1976 u'v' | CIE 2000 UCS | CAM16-UCS |
| --- | --- | --- | --- | --- |
| sRGB / Rec. 709 | 33.5 | 33.3 | 48.6 | 46.4 |
| NTSC (1953) | 47.3 | 38.1 | 59.4 | 55.3 |
| DCI P3 (ST 428-1) | 45.5 | 41.7 | 61.5 | 56.5 |
| Adobe RGB (1998) | 45.2 | 38.8 | 55.7 | 53.8 |
| Rec. 2020 (UHD / HDR) | 63.4 | 57.3 | 75.2 | 68.9 |
| ProPhoto RGB | 79.2 | 76.7 | 90.6 | 83.0 |

> u'v' 列 2026-08-31 修正：此前正向公式误写为 `x+4y+16z`（正确为 CIE 标准的
> `u'=4x/(x+15y+3z)`、`v'=9y/(x+15y+3z)`，D65 → (0.19783, 0.46832)），色场
> 反变换的 `Z/Y` 公式同步修正为 `(12−3u'−20v')/(4v')`。修正前 u'v' 画布的
> 色域三角形、D65 点与背景色整体错位，本列旧数值一并作废。

现代 UCS 在感知均匀的意义上"放大"了色度空间，同一色域的 % visible 数值会随 UCS 变化，**不同 UCS 的百分比之间不能直接比较**（同 UCS 内相互比较才自洽）。

**内置参考色域库（13 项，4 类）**

| 类别 | 色域 | 标准 | 白点 |
| --- | --- | --- | --- |
| Display / Video | NTSC (1953) | NTSC 1953 | D65 |
| | Rec. 601 / 170M (SDTV) | ITU-R BT.601 / SMPTE 170M | D65 |
| | EBU R 39 (PAL / SECAM) | EBU R 39-2005 | D65 |
| | sRGB / Rec. 709 | ITU-R BT.709 / SMPTE 274M, 347M / IEC 61966-2-1 | D65 |
| | Rec. 2020 (UHD / HDR) | ITU-R BT.2020, 2100 / SMPTE ST 2084, 2094, 2110 | D65 |
| Cinema (SMPTE) | DCI P3 (ST 428-1) | SMPTE ST 428-1 / 428-7 | DCI (0.3140, 0.3510) |
| | Display P3 (Apple) | Apple Display P3 | D65 |
| Design / RGB working spaces | Adobe RGB (1998) | Adobe (1998) | D65 |
| | ProPhoto RGB | Adobe ProPhoto | D50 |
| | CIE 1931 RGB | CIE 1931 | E (1/3, 1/3) |
| Print / CMYK (approx.) | ISO Coated v2 (FOGRA 39) ≈ | ISO 12647-2 | D50 |
| | SWOP v2 ≈ | ISO 12647-4 | D50 |
| | GRACoL 2006 ≈ | ECP G7 | D50 |

说明：
1. 各 UCS 的百分比以**该 UCS 可见色域**（马蹄形 380–780 nm + 紫线，面积见上表）的实际面积为统一分母、交集为分子，同一 UCS 内自洽；与文献中常见数字（分母 / 口径不同）不能直接对等，不同 UCS 之间也不能互比。
2. 三个 **印刷** 条目为近似值（列表中以 `≈` 标注、图上以虚线多边形绘制）：ISO 12647-x / ECP G7 等印刷标准规定的是油墨光谱与密度容差，**并不规定基色色度坐标**；表中数值为标准印刷条件下的合成基色估计，仅面积量级有意义（CIE 1931 口径下约 10–11%，明显小于 sRGB 的 ~33.5%）。
3. 含**虚像基色**的色域（如 ProPhoto RGB 的蓝基色 XYZ 分量为负）在两套 CAM-UCS 下只能取模型可表示的边界部分（不可表示采样点被剔除），其 CAM-UCS 数值为近似；CIE 1931 / u'v' 下无此限制。

### 8.4 CRI / R-values（显色指数）

- 选择一条光谱，计算 `Ra`（综合显色指数）、`CCT` 与 `xy`
- 条形图显示各特殊显色指数 `R1–R14`：
  - 绿色 ≥ 90，琥珀色 ≥ 80，橙色 60–80，红色 < 60
- 当前 `colour` 库版本仅提供到 `R14`（无 `R15`）

## 10. 常见问题

### 1. 程序能打开，但串口列表为空

请检查：

- 设备是否已接入
- 驱动是否正常
- 是否需要点击 `Refresh`

### 2. 连接失败

请检查：

- 当前选择的串口是否正确
- 串口是否被其他程序占用
- `PR788` 是否已经正常上电

### 3. 测量等待很久

这不一定是错误。  
当前程序默认会耐心等待 `PR788` 返回完整数据，特别是在某些读数较慢的场景下，等待时间可能明显变长。

### 4. 颜色预览和实际观感不完全一致

这是正常的。  
`sRGB Preview` 只是基于测量结果做的屏幕参考显示，不等同于真实发光体在实际环境中的肉眼观感。

## 11. 当前推荐使用方式

如果你只是进行日常测量，推荐这样使用：

1. 启动程序
2. 选择串口并连接
3. 设置输出目录
4. 使用 `{counter}_{timestamp}` 作为文件名模板
5. 打开自动编号
6. 连续点击 `Capture Measurement`
7. 在右侧查看 `SPD`、`CCT`、`Tint` 和颜色预览

这样是当前最稳定、最直接的使用路径。
